# Brainstorm Archive

本目录用于归档**有参考价值但尚未形成正式决策**的架构设想、讨论线索、候选模型和问题清单。

## 定位

- 非 ADR；
- 非机器运行 SSOT；
- 非已批准架构；
- 可以包含互相竞争、尚未验证或未来可能被否决的想法；
- 任何内容只有在后续进入 ADR / Contract / Schema / Governance 并完成评审后，才成为正式基线。

## 使用规则

1. 保留问题、假设、候选方案及其上下文，不只保留最终结论；
2. 每篇文档明确状态、日期、与正式 ADR 的关系；
3. 已被正式决策吸收的内容可保留，但应标记对应 ADR / Contract；
4. 被否决的想法不必删除，可标记 rejected / superseded，供后续避免重复讨论；
5. Brainstorm 内容不得覆盖 `研发中心AI数字员工研发流程规划.md`、ADR、机器 Contract 或专家团治理资产。
