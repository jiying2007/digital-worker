# 采用范围与正式集成策略

## 个人和小团队的当前入口

[小团队按需采用与资产保留](small-team-optional-adoption.md)规定日常采用范围：使用三类任务模板、现有模型 CLI、ADK 和项目 Git/CI；本仓作为可选方法和证据参考。2026-11-18 的入口收敛延续 2026-09-24 已接受的非必选方向。

## 显式选择正式集成时阅读

以下基线保留其原有合同和证据语义，不作为普通项目的部署清单或全部待建功能：

- [AI R&D Target Operating Model](ai-rd-target-operating-model.md)：原有跨仓职责、L0/L1/L2 和 exact-source-set 身份语义。
- [Cross-Repo Terminal Maturity Landing](cross-repo-terminal-maturity-landing.md)：原有成熟度轴、Pilot 与资格边界；采用收敛不等于这些资格已完成。
- [R0 Trust Closure](r0-trust-closure.md)：真实 Pilot 的来源、证据、Runtime 身份和阶段化治理。
- [Embedded Domain Closed Loop V1](embedded-domain-closed-loop-v1.md)：正式嵌入式任务的工程、质量、知识和能力闭环参考。

正式集成的长期语义以[ADR-005](../adr/ADR-005-cross-repo-semantic-ownership-and-evidence-federation.md)与相关机器合同为准。策略说明采用范围，不能把已有未验证结果提升为通过，也不复制其它仓库的事实权威。

历史优先通过 Git history 和[参考索引](../reference-index.md#历史证据与版本边界)追溯。现有 Pilot/R2/产品证据保留原路径和身份；本次收敛不删除历史材料，不批量关闭未完成项。
