# Architecture Impact Analysis

Assess impact on software layers, boot/runtime boundaries, tasks/threads, IPC, memory, power states, fault containment, API/ABI and portability.

Output affected components, compatibility risk, constraints, alternatives and verification needs. Separate observed architecture facts from inferred impact. Do not prescribe code before identifying affected contracts.
