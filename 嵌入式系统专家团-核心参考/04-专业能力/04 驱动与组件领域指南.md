# 驱动与组件领域指南

> 岗位职责与任职资格见 [《数字岗位与能力模型》](../01-数字组织与岗位/03%20数字岗位与能力模型.md)。本文只描述**驱动与组件专业工作怎么做**。

## 1. 领域定位

驱动与组件负责把具体硬件能力可靠接入系统，并把一次性项目实现收敛为可维护、可测试、可诊断、可移植的接口。

## 2. 典型任务

设备 Bring-up、Linux/MCU Driver 集成、Platform Adapter、Stable API、器件替代、国产化/第二供应商导入、错误恢复、Power/Suspend/Resume 和跨平台组件化。

任务路由和 Mode 只在 [任务类型运行矩阵](../03-流程与运行/05%20任务类型运行矩阵.md) 维护。

## 3. 必要输入

- hardware/board/device identity；
- datasheet/TRM/schematic；
- bus/protocol；
- Linux/MCU 平台资源；
- current driver/component/API；
- error/timeout/power 行为；
- firmware/NVM/calibration；
- 目标平台和真实复用范围。

## 4. 分析方法

```text
Hardware / Bus
→ Low-level Driver
→ Platform Adapter
→ Stable Component API
→ Application / Service
```

平台事实尽量停留在底层和 Adapter，不让业务层长期绑定 DTS 节点、寄存器地址或板级 GPIO 编号。

### Driver Integration

依次检查 identity/resource、init/probe/deinit、IRQ/DMA/thread context、error/timeout/retry、power/suspend/resume、concurrency/lifetime、API/ABI/version、logging/diagnostics、build/config、test/rollback/field diagnosability。

### 器件替代

Compatibility Matrix 至少覆盖电气/板级、总线协议、初始化、能力差异、时序/性能、异常行为、firmware/NVM、Linux/MCU 接口、生产校准/测试和回归范围。

### 组件化

只有在多个真实平台/项目重复使用、差异点可隔离、stable API 能覆盖真实需求、测试/诊断方法可复用且抽象不隐藏关键硬件约束时，才适合沉淀公共组件。

## 5. Evidence 要求

“API 兼容、能编译”只能证明很小一部分兼容性。Driver/Component 结论应绑定 device/board、平台资源、初始化/错误/Power 路径、目标设备行为和必要性能/长稳 evidence；器件替代还需要明确产品/board/SDK/device revision。

## 6. 输出

Driver Integration Review、Compatibility Matrix、Stable API / Platform Adapter 建议、error/power/concurrency 行为、平台差异、回归范围、技术债和 Verification 要求。

## 7. 协作与交接

- P03：Linux/BSP resource、DT、IRQ/DMA、平台事实；
- P04：MCU scheduling、ISR/DMA、实时性和 MCU driver 事实；
- P02：系统职责、接口和公共 API 边界；
- P06：未知原因的复杂设备异常和 Root Cause；
- P07：目标设备、兼容和回归 Evidence 的独立验证。

## 8. 常见错误

- init 成功但 deinit/error recovery 缺失；
- timeout 后 resource/lifetime 未恢复；
- suspend/resume 只测正常路径；
- API 过度暴露平台细节；
- workaround 无适用条件和退出计划；
- 替代器件只做功能 smoke，不测异常/功耗/生产流程；
- 日志无法定位 bus/device/error state；
- 为尚不存在的第三个平台提前增加复杂抽象。

## 9. BLOCK 条件

设备/board identity 不清、平台资源事实未确认、datasheet/协议关键语义缺失、目标复用范围不明确却要求公共抽象、替代器件缺异常/Power/生产约束或关键兼容维度无 Evidence 时，应 BLOCK 或明确保持候选状态。
