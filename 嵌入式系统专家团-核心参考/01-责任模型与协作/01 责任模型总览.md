# 责任模型总览

本页定义核心参考中的责任语言。机器权威是 `domains/edge-foundation/domain.yaml`；本页只做人类解释，不创建第二份组织 SSOT。

## 1. 领域边界

Edge Foundation Domain 面向端侧/嵌入式系统基础能力，当前正式 Domain Experts 只有三个：

- **Structure Expert**：结构与机械相关专业责任；
- **Hardware Expert**：硬件、电气、器件与板级专业责任；
- **Embedded System Expert**：Linux / RTOS / MCU / Driver / Debug 等嵌入式软件专业责任。

**Edge Coordination** 是跨任务协调 Role，负责接单、材料准备度、路由、Gate、交接与 Closure；它不是第四个 Expert。

## 2. Embedded System Expert 的内部组织方式

Embedded System Expert 不再拆成多个正式 Expert 身份，而通过 5 个 Capability 组织专业能力：

| Capability | 责任边界 | 典型问题 |
|---|---|---|
| `embedded.architecture` | 系统边界、接口、资源、质量属性、平台影响 | 架构设计、可行性、跨仓接口、资源预算 |
| `embedded.linux-bsp` | Boot、Kernel、DT、IRQ/DMA、Storage、Power、BSP | 启动、UBI/UBIFS、DMA/cache、Bring-up |
| `embedded.mcu-rtos` | Startup、Linker、ISR/DMA、RTOS、Watchdog、MCU OTA | HardFault、ROM/RAM、并发、实时性 |
| `embedded.driver-component` | Driver、Protocol、Adapter、Stable API、器件替代 | 驱动集成、组件化、兼容矩阵 |
| `embedded.debug-reliability` | Timeline、Hypothesis、RCA、长稳、性能与故障分析 | Crash、内存、死锁、现场故障、性能退化 |

Capability 是责任组织单元，不是 Agent、Worker 或独立组织岗位。实际 Runtime 可以用一个或多个 Agent/Session 承载同一 Capability，也可以由人完成。

## 3. Assurance 独立于 Embedded Capability

可信保障平面至少包含：

- **Verification**：把 Acceptance 映射到直接 Evidence，判断每一验证层实际证明到哪里；
- **Independent Review**：在需要时独立检查证据、风险、错误放行与 Release Readiness。

它们不是 `embedded.*` Capability，也不能因为当前由同一个 Runtime 执行就改变责任归属。

当前 iterative Pilot 阶段若 Independent Review 不可用，可由 static checks + Hosted CI + traceable Verification evidence 满足 Pilot completion；这一阶段性替代不改变长期 Assurance 责任模型。

## 4. 四个稳定平面

```text
Responsibility Plane  谁对专业结论负责
Orchestration Plane   任务如何分解、路由和恢复
Execution Plane       人与 Runtime 如何实际执行
Assurance Plane       如何独立证明、阻断错误 PASS、控制发布风险
```

组织结构不绑定 Agent topology：Expert 数、Worker 数、Session 数、Skill 数互不等价。

## 5. 权威来源

- Domain / Expert / Capability / Assurance：`domains/edge-foundation/domain.yaml`
- Skill ownership：`domains/edge-foundation/skills.yaml`
- Gate ownership：`domains/edge-foundation/gate-policy.yaml`
- Target routing semantics：`domains/edge-foundation/routing-shadow.yaml`
- Golden Cases：`domains/edge-foundation/evaluation/golden-cases.yaml`
- 旧执行身份映射：`domains/edge-foundation/compatibility/embedded-1plus7-mapping.yaml`

旧映射只服务迁移与 rollback 审计，不应重新出现在目标责任文档中。
